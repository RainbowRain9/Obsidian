## 二、第四章：指令系统

指令系统是计算机所有程序的基础，从最底层的微指令到高级程序均由其构成。

### 1. 指令层级

*   **微指令 (Micro-instruction)**：计算机中最低级的指令层面，用于识别和执行更高级的指令。
*   **机器指令 (Machine Instruction)**：介于微指令和宏指令之间，是计算机硬件能直接识别和执行的指令。
*   **宏指令 (Macro-instruction)**：属于软件层面，用于方便程序编写。
*   **层级关系**：每条指令包含微指令，微指令又包含微操作。

### 2. 指令格式

*   **核心组成**：一条指令中最核心的两个部分是**操作码 (Opcode)** 和 **操作地址 (Operand Address)**。
*   **操作码**：决定指令执行的具体操作。其位数决定了计算机支持的指令数量（例如，8位操作码可以表示 $2^8 = 256$ 条指令）。
*   **指令长度**：分为定长指令和不定长指令。现代计算机（特别是精简指令系统）多采用定长指令。
*   **地址个数**：指令可根据包含的地址数量分类，如四地址、三地址、两地址、一地址、零地址指令（通常包含隐含地址）。

### 3. 寻址方式

寻址方式是计算操作数有效地址的方法，是学习和考试中的重点。

*   **直接寻址**：地址码直接给出操作数的有效地址。
*   **寄存器寻址**：操作数在寄存器中，指令中直接给出寄存器编号。
*   **寄存器间接寻址**：寄存器中存储的是操作数的地址。
*   **基址寻址**：有效地址 = 基址寄存器内容 + 偏移量 (displacement)。
*   **变址寻址**：有效地址 = 变址寄存器内容 + 偏移量。
*   **相对寻址**：有效地址 = 程序计数器 (PC) 当前值 + 偏移量。常用于处理补码表示的负数偏移，需要进行符号扩展。
*   **隐含寻址**：地址隐含在操作码或指令格式中，无需显式给出。
*   **堆栈寻址**：操作数位于堆栈顶部，通过堆栈指针访问。
*   **扇区寻址**与**页式寻址**：涉及分段和分页机制。

### 4. 复杂指令系统 (CISC) 与精简指令系统 (RISC)

*   **复杂指令系统 (CISC)**：指令数量多，功能复杂。
*   **精简指令系统 (RISC)**：当前计算机的主流趋势，需要了解其优点，例如**减少内存访问次数**。

## 三、第五章：CPU组成与控制

CPU是计算机的核心部件，主要由运算器和控制器构成。

### 1. CPU主要组成

*   **核心部件**：运算器 (ALU) 和控制器 (Control Unit)。
*   **内部结构**：需了解CPU构成图，包括各种寄存器（如指令寄存器、指针寄存器、数据地址通用寄存器、状态字寄存器等）。

### 2. 控制器实现方式

*   **硬布线控制器 (Hardwired Control Unit)**
    *   **实现**：通过组合逻辑电路和触发器实现。
    *   **优点**：速度快。
    *   **缺点**：结构复杂，难以修改和扩展。
*   **微程序控制器 (Microprogrammed Control Unit)**
    *   **实现**：通过存储微程序来控制指令的执行，灵活性更高。
    *   **微程序与微指令**：微程序由一系列微指令组成，微指令是更小的单位，包含微操作。
    *   **微指令编码方式**：
        *   **直接表示法**：每个微操作控制信号在微指令字中占一位。优点是直观，缺点是微指令字长。
        *   **编码表示法（间接编码）**：将互斥的微操作编码，以较少的位数表示多个微操作（例如，3位编码可表示8个微操作）。
        *   **混合表示法**：结合直接和编码表示法，是最常见的方式。
    *   **微指令字长计算**：需要综合考虑直接表示、编码表示、下地址和分支条件所需的位数。

### 3. 指令周期 (Instruction Cycle)

*   **执行阶段**：通常分为**取指令 (Fetch Instruction)**、**取操作数 (Fetch Operand)** 和 **执行 (Execute)** 三个阶段。
*   **并行操作**：取指令和取操作数可以并行进行。

### 4. 流水线技术 (Pipelining)

*   **核心原理**：**并行处理**。将一条指令的执行分解为多个阶段，使得多个指令的不同阶段可以同时执行，从而大幅提高CPU的运行速度。

## 四、第六章：总线系统与I/O

总线是连接计算机内部各部件及外部设备的关键。

### 1. 总线系统

*   **总线分类**：
    *   按传输方式：**串行总线**（抗干扰能力强，应用更广）和**并行总线**。
    *   按连接方式：单种总线、双种总线等。
*   **总线带宽 (Bus Bandwidth)**：
    *   **定义**：衡量总线的**吞吐量**，即单位时间内能传输的数据量，单位通常是字节/秒 (bytes/s)。
    *   **计算**：涉及传输字节数、时钟频率和每个时钟周期传输的数据量等。
*   **总线仲裁 (Bus Arbitration)**：解决多个设备同时请求使用总线时的优先级问题。
    *   **菊花链式 (Daisy Chain)**：设备串联，优先级由物理位置决定（越靠近CPU优先级越高）。优点是结构简单（仅需三根线），缺点是优先级固定且可靠性较低。
    *   **集中式查询 (Centralized Polling)**：由中央仲裁器轮流查询设备。优点是优先级可编程，缺点是需要较多地址线。
    *   **独立请求式 (Independent Request)**：每个设备都有独立的请求线和允许线。优点是速度最快，优先级分配灵活，缺点是所需总线线路最多（2n+1根）。
*   **总线读写方式**：
    *   写后读 (Write-after-read)
    *   读修改写回 (Read-modify-write)

### 2. I/O工作方式

这是I/O章节的重点，需要重点比较四种方式的特点。

*   **程序查询方式 (Programmed I/O / Polling)**
    *   **特点**：CPU不断循环查询I/O设备的状态。
    *   **优缺点**：实现简单，但CPU效率极低，已被淘汰。
*   **中断方式 (Interrupt-driven I/O)**
    *   **特点**：I/O设备在准备就绪后，主动向CPU发送中断请求。
    *   **优点**：CPU无需等待，效率相比查询方式更高。
*   **直接存储器访问 (DMA, Direct Memory Access)**
    *   **特点**：在DMA控制器下，I/O设备和内存之间直接进行数据传输，无需CPU干预。
    *   **优点**：专为内存传输设计，大大提高了数据传输效率。
*   **通道方式 (Channel)**
    *   **特点**：比DMA更高级，通道本身是一个独立的处理器，可执行通道程序，管理多个I/O设备。
    *   **优点**：进一步解放CPU，实现更高的I/O并行性。

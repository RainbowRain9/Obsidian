## 🤖 Agent系统设计

### 1\. 多Agent架构（一个角色一个Agent）[^1](%5BD:%5CCode%5CHeartChat%5Cdoc%5C%E5%BC%80%E5%8F%91%E6%96%87%E6%A1%A3%5Cdatabase%5Croles.md%5D\(D:%5CCode%5CHeartChat%5Cdoc%5C%E5%BC%80%E5%8F%91%E6%96%87%E6%A1%A3%5Cdatabase%5Croles.md\))

林云老师建议采用"一个角色一个Agent"的设计模式，便于报告撰写和技术展示：

#### 1.1 情感分析Agent

-   **功能**：实时情感分析、情感维度分析、情感趋势预测 [^3](%5BREADME.md%5D\(http://file/ddbaa3ee-ef14-4fa6-95c3-057818153196.md\))[^6](%5BD:%5CCode%5CHeartChat%5Cdoc%5C%E5%BC%80%E5%8F%91%E6%96%87%E6%A1%A3%5Ccloudfunctions%5CgenerateDailyReports.md%5D\(D:%5CCode%5CHeartChat%5Cdoc%5C%E5%BC%80%E5%8F%91%E6%96%87%E6%A1%A3%5Ccloudfunctions%5CgenerateDailyReports.md\))
    
-   **输入**：用户对话内容
    
-   **输出**：情感类型、强度、趋势分析结果
    

#### 1.2 心理健康引导Agent

-   **功能**：基于情感分析结果提供个性化心理指导
    
-   **输入**：情感分析结果 + 用户画像
    
-   **输出**：安抚话术 + 行为建议 + 资源推荐
    

#### 1.3 场景化专业Agent

林云老师强调要覆盖多种心理问题场景，分类要尽量细：

-   **家庭矛盾处理Agent**：处理家庭关系问题
    
-   **学业压力缓解Agent**：处理学业相关问题
    
-   **考试焦虑疏导Agent**：处理考试压力问题
    
-   **宿舍关系调解Agent**：处理宿舍人际关系
    
-   **情感问题咨询Agent**：处理恋爱和情感问题
    

#### 1.4 预警干预Agent

-   **功能**：心理问题识别、风险评估、预警推送
    
-   **输入**：情感分析 + Token组合分析
    
-   **输出**：预警级别 + 干预建议 + 转接决策
    

#### 1.5 树洞社交Agent

-   **功能**：匿名分享、内容审核、主动安抚
    
-   **输入**：用户分享内容
    
-   **输出**：匹配响应 + 社区互动
    

## 🔄 工作流设计

### 1\. 主对话工作流

```text
用户输入 → 消息预处理 → 情感分析 → 用户画像查询 → 
角色匹配 → 对话生成 → 消息分段 → 输出用户
```

### 2\. 情感分析工作流 [^3](%5BREADME.md%5D\(http://file/ddbaa3ee-ef14-4fa6-95c3-057818153196.md\))[^6](%5BD:%5CCode%5CHeartChat%5Cdoc%5C%E5%BC%80%E5%8F%91%E6%96%87%E6%A1%A3%5Ccloudfunctions%5CgenerateDailyReports.md%5D\(D:%5CCode%5CHeartChat%5Cdoc%5C%E5%BC%80%E5%8F%91%E6%96%87%E6%A1%A3%5Ccloudfunctions%5CgenerateDailyReports.md\))

```text
对话内容 → 文本预处理 → 多维度情感分析 → 
情感强度评估 → 情感趋势分析 → 结果存储 → 反馈用户
```

### 3\. 智能推理工作流

林云老师提出的Token组合推理机制：

```text
Token提取 → 组合分析 → 场景推理 → 问题识别 → 
Agent匹配 → 干预策略生成 → 响应输出
```

**示例推理逻辑**：

-   易怒 + 自卑 + 胆小 → 可能存在家庭暴力问题
    
-   焦虑 + 失眠 + 担忧 → 可能存在学业压力问题
    

### 4\. 预警转接工作流

```text
风险评估 → 预警级别判断 → 人工转接决策 → 
专业人员匹配 → 信息整理 → 转接执行 → 跟踪反馈
```

## 📚 知识库系统

### 1\. 情感知识库

-   **情感分类标准**：基础情感和复合情感分类
    
-   **情感强度评估**：1-10级量化标准
    
-   **情感干预策略**：安抚话术库、调节方法库
    

### 2\. 场景知识库

林云老师要求覆盖多种心理问题场景：

-   **家庭矛盾**：亲子关系、家庭沟通等
    
-   **学业压力**：学习困难、考试焦虑等
    
-   **人际关系**：宿舍问题、师生关系等
    
-   **情感问题**：恋爱困扰、分手痛苦等
    

### 3\. 用户画像库 [^1](%5BD:%5CCode%5CHeartChat%5Cdoc%5C%E5%BC%80%E5%8F%91%E6%96%87%E6%A1%A3%5Ccloudfunctions%5Croles.md%5D\(D:%5CCode%5CHeartChat%5Cdoc%5C%E5%BC%80%E5%8F%91%E6%96%87%E6%A1%A3%5Ccloudfunctions%5Croles.md\))

-   **兴趣偏好**：用户兴趣点分析
    
-   **沟通风格**：沟通特点分析
    
-   **情感模式**：情感反应模式识别
    

### 4\. 专业资源库

-   **心理咨询师信息**：专业领域、联系方式
    
-   **辅导员信息**：负责院系、专业背景
    
-   **校园资源**：心理咨询中心、学业指导中心
    

## 🎯 实施重点

### 1\. 帮助性提升（解决现有问题）

-   **从分析到干预**：不仅提供情绪数据统计，更要提供实际安抚和行为建议
    
-   **人机结合**：整合AI智能分析和人工专业关怀，参考省二项目经验
    
-   **个性化服务**：基于用户画像的个性化心理指导
    

### 2\. 技术差异化

-   **自训练语料库**：林云老师强调要自己训练语料库做情感分类，避免被质疑只是调用API
    
-   **场景细化**：分类要尽量细，与常规接API的产品形成差异化
    
-   **Token推理**：通过Token组合推导用户的心理问题场景
    

### 3\. 实用性增强

-   **即时安抚**：对负面情绪给予即时安抚和行为建议
    
-   **主动关怀**：系统主动识别问题并提供帮助
    
-   **专业转接**：必要时转接心理咨询师和辅导员
